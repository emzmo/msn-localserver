Client Setup Guide

This page contains everything needed to set up a Windows XP PC to connect to the MSN Museum server.

Step 1: Install the CA Certificate

The server uses a self-signed certificate. You must install this CA certificate on each XP machine, or MSN Messenger will not trust the server.

  1. Download msn-museum-ca.crt
  2. Double-click the downloaded file
  3. Click Install Certificate...
  4. Select Place all certificates in the following store
  5. Click Browse... and select Trusted Root Certification Authorities
  6. Click Next then Finish

Step 2: Edit the Hosts File

On each XP machine, open C:\WINDOWS\system32\drivers\etc\hosts in Notepad and add these lines (replace {{ server_ip }} with the server's IP if different):

{{ server_ip }}  messenger.hotmail.com
{{ server_ip }}  messenger.msn.com
{{ server_ip }}  nexus.passport.com
{{ server_ip }}  login.passport.com
{{ server_ip }}  login.live.com
{{ server_ip }}  config.messenger.msn.com
{{ server_ip }}  contacts.msn.com
{{ server_ip }}  byrdr.omega.contacts.msn.com
{{ server_ip }}  storage.msn.com
{{ server_ip }}  tkrdr.storage.msn.com
{{ server_ip }}  ows.messenger.msn.com
{{ server_ip }}  rsi.hotmail.com
{{ server_ip }}  gateway.messenger.hotmail.com

Step 3: Clear Registry Cache (MSN 1.0–6.2 only)

Older MSN versions cache the server IP in the registry. If the client won't connect after setting up the hosts file, delete this registry value:

  • MSN 1.0–4.7: HKEY_CURRENT_USER\SOFTWARE\Microsoft\MessengerService\Server
  • MSN 5.0–6.2: HKEY_CURRENT_USER\SOFTWARE\Microsoft\MSNMessenger\Server

Windows Messenger 4.7 and MSN 7.0+ do not need this step.

Step 5: Sign In

Launch MSN Messenger and sign in with the email and password provided by museum staff. The server address will be resolved automatically via the hosts file — no manual server configuration needed.

Note: If you are using MSN 7.5, you may see error 80048820 at sign-in. This is a known issue with WinHTTP on XP and our TLS gateway. Windows Messenger 4.7 (included with XP) or MSN 7.0 are recommended alternatives that work correctly with the museum server.
