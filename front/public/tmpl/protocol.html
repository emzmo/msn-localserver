MSNP 2-12

MSN Messenger Protocol (MSNP) is the text-based protocol used by MSN Messenger and Windows Live Messenger clients to communicate with the server. It uses plain TCP on port 1863 for the Notification Server (NS) and port 1864 for the Switchboard (SB) chat sessions.
